# 投屏导航 SE APK

这是用于分发“投屏导航 SE”Android APK 的仓库。

## 最新版本

- 版本：`1.02`（`versionCode 2`）
- 标签：[`v1.02`](https://github.com/xmz28/mirror-nav-se-apk/releases/tag/v1.02)
- APK：[下载最新 Release APK](https://github.com/xmz28/mirror-nav-se-apk/releases/download/v1.02/tou-ping-nav-se-release-v1.02.apk)
- 包名：`com.example.bleconnectse`

## 功能

- **仪表投屏**：连接仪表 AP 或 P2P 后，支持相册媒体、摄像头和手机屏幕投屏。
- **仪表壁纸**：选择手机中的图片并设置为仪表壁纸。

## 仪表端兼容性

- **投屏**：所有仪表端均支持。
- **壁纸**：仅当仪表端固件达到下列最低版本时支持。

| 仪表尺寸 | 壁纸最低仪表端版本 |
| --- | --- |
| 5 寸 | 1.44 |
| 6 寸 | 1.28 |
| 7 寸 | 1.94 |

> 低于对应版本的仪表端仍可使用投屏，但不支持设置壁纸。请先确认仪表端固件版本。

## 安装与使用

1. 下载并在 Android 手机上安装最新 APK。
2. 在应用中连接仪表 AP 或 P2P。
3. 使用“相册媒体”“摄像头”或“手机屏幕”进行投屏；仪表端满足最低版本时，可使用“设置壁纸”。
